A model-agnostic graph framework for global and local explanation of tree-based ensembles. DPG turns an ensemble's decision logic into one graph of predicates, transitions and predictions you can inspect.

How it works

  1. Tabular datasetfeatures + labels
  2. Tree-based ensembleRF · GB · ET · AdaBoost · Bagging
  3. Predicate extractionpaths → nodes and edges
  4. DPG constructionweighted graph
  5. Analysis & insightscentrality · communities · local paths

Nodes are the predicates found in every node of every tree. Edges count how often the training samples satisfy one predicate after another.

What the graph tells you

Constraints

The value intervals of each feature along every path that ends in a class, i.e. the classification boundaries of each class.

Betweenness centrality

The share of shortest paths passing through a node. High values flag bottleneck predicates: the crucial decisions.

Local reaching centrality

How much of the graph a node reaches. Like feature importance, but tied to the feature values used in every decision.

Communities

Densely connected groups of predicates per class, separating the dominant decisions from the marginal ones.

Beyond the global graph: local explanations per sample, local-on-global plots, and faithfulness diagnostics. See the visualization guide.

Get started

1 Install the package

$ pip install dpg

Requires Python 3.10 or newer.

2 Add Graphviz for rendering

The dot executable must be on your PATH to draw graphs.

macOS
brew install graphviz
Ubuntu / Debian
sudo apt-get install graphviz
Windows
winget install Graphviz.Graphviz

3 Explain a random forest

import numpy as np
from sklearn.datasets import load_iris
from sklearn.ensemble import RandomForestClassifier
from dpg import DPGExplainer

X, y = load_iris(return_X_y=True, as_frame=True)
model = RandomForestClassifier(n_estimators=5, random_state=42).fit(X, y)

explainer = DPGExplainer(
    model=model,
    feature_names=X.columns.tolist(),
    target_names=np.unique(y).astype(str).tolist(),
)
explanation = explainer.explain_global(X.values, communities=True)
explainer.plot_communities("iris_dpg", explanation, save_dir="results")

This writes the community graph shown above to results/. Prefer the terminal? The dpg command does the same:

$ dpg --dataset iris --n_learners 5 --plot --communities

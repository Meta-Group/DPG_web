Counterfactuals

What is the smallest change that would make the model decide differently? DPG-CF answers with counterfactual examples. It reads class intervals for each feature off the model's Decision Predicate Graph, combines them with rules about which features may change and in which direction, and searches inside them. The search never looks at the training data. Everything runs in your browser.
